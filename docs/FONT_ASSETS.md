# Personalized media font assets

ReviewOrbit bundles the following font files from the official Google Fonts repository under the SIL Open Font License 1.1: Poppins, Montserrat, Playfair Display, Pacifico, Great Vibes, Lobster, Sacramento, and Allura. The OFL license text is retained alongside the backend font assets in `apps/api/resources/fonts`.

Sources:

- <https://github.com/google/fonts/tree/main/ofl/poppins>
- <https://github.com/google/fonts/tree/main/ofl/montserrat>
- <https://github.com/google/fonts/tree/main/ofl/playfairdisplay>
- <https://github.com/google/fonts/tree/main/ofl/pacifico>
- <https://github.com/google/fonts/tree/main/ofl/greatvibes>
- <https://github.com/google/fonts/tree/main/ofl/lobster>
- <https://github.com/google/fonts/tree/main/ofl/sacramento>
- <https://github.com/google/fonts/tree/main/ofl/allura>

The browser copies live under `apps/web/public/fonts`. Font names are selected from a server allowlist; uploaded font files and arbitrary filesystem paths are not accepted.
